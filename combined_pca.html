Combined waveform and spectral analysis

This fit joins all 27 waveform-morphology descriptors with 12 harmonic-masked spectral descriptors for V2, V1−V2 and V3−V4. Waveform and spectral blocks each contribute half of the input variance, so feature count alone does not determine their relative influence. This equal weighting is an exploratory analysis choice.

The waveform descriptors retain shape and channel correlations; spectral descriptors add peak frequency, fractional FWHM, peak power fraction and contrast. The 150/300/450/600/750 kHz supply harmonics are masked before peak selection. Only events valid in both analyses enter this fit; no missing values are filled. Three Ward groups are browsing labels, not physical classes.

The first three PCs describe a projection of the full 39-feature space. Neighbors use all 39 features, not just this display. Original E23 dust annotations cannot be inferred from these new coordinates.
